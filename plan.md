# План работ на 2026 год

## Цель проекта

Направление - программирование и IT в целом.

Создать приложение, которое:

* работает по аналогии Duolingo
* разбивает запрос обучения через промт на подтемы-задания
* задания выставляются по дедлайну
* целеполагание по подзадачам

## User Story

Это глобальные шаги, к которым хотим придти:

* формирует запрос в систему
* получает перечень подтем для изучения
* подтемы ставятся задачами для пользователя
* выставляются дедлайны
* подтемы объединены одной целью (цель в запросе пользователя)
* трекам дедлайны и работаем с ними

## Примерная архитектура 1 итерации

* сервис коммуникации с пользователем через telegram

    * микросервис, аля типо echo-bot
    * dockerfile - запустить локально в контейнерах два echo-бота

* сервис ручной постановки `простой` задачи

    * запросы в сервис только с наших локальных контейнеров (закрыто с внешки)
    * авторизации и аутентификации пользователя (упрощенная по user_id)
    * где храненим информацию (sqlite, postgres и т.д.)
    * REST API микросервиса:

        * GET запрос, список имеющихся задач пользователя
        * POST запрос, создание новой задачи пользователя

## Следующие шаги для планирования

* прикручивать возможность ставить дедлайны на задачу
* мониторить наступление дедлайнов по задачам
* уведомление пользователя о наступлении дедлайне
